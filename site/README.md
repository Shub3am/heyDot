# Hey Dot Frontend

This frontend is the presentation site for Hey Dot, the fully local desktop AI assistant.

It highlights the core product message used by the runtime app:

- Fully local AI
- No cloud dependency
- No API key requirement
- Private, on-device voice + screen intelligence

## Stack

- React
- Vite
- CSS

## Scripts

- `npm run dev`: Start local dev server
- `npm run build`: Create production build
- `npm run preview`: Preview production build
- `npm run lint`: Run ESLint

## Run Locally

```bash
cd frontend
npm install
npm run dev
```

## Main Entry

- `src/App.jsx`: Landing page content and structure
